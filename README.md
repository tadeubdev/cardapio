# Cardapio

Este repositorio e um projeto de estudos.

A ideia aqui e praticar o desenvolvimento de uma API com foco em backend, organizacao de camadas e persistencia de dados.

## Tecnologias que estou estudando

- Java 21
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- PostgreSQL
- Flyway (migracoes de banco)
- Maven
- Lombok

## Objetivo do projeto

Estudar na pratica como construir uma API REST para gerenciamento de itens de cardapio, incluindo:

- criacao de endpoints
- validacao e tratamento de erros
- integracao com banco de dados relacional
- versionamento de schema com migracoes

## Status

Projeto em evolucao para aprendizado continuo.
